# Island — динамічний острів для Windows

Рідка «пілюля» вгорі екрана, що оживає під музику, показує сповіщення, передає файли на телефон і тримає під рукою все, чим ви користуєтеся щодня. Для Windows 10 і 11.

**[⬇ Завантажити останню версію](../../releases/latest)** · [Сайт проєкту](https://freshman-69.github.io/Island-win/)

## Що вміє

- **Музика:** будь-який плеєр (Spotify, YouTube, Apple Music, AIMP…), обкладинка, хвиля під ритм, синхронний текст пісні, ♥ у Spotify.
- **Сповіщення:** Telegram з відповіддю прямо з острова, Discord, Gmail, «Зв’язок з телефоном» та інші. Серії повідомлень складаються в один тост.
- **Телефон ⇄ ПК:** файли до 2 ГБ і текст через ваше «Збережене» в Telegram з будь-якої мережі або через QR-код у Wi-Fi.
- **Полиця:** перетягніть файли на острів, вони почекають. Там же нотатки, які можна одним кліком надіслати на телефон.
- **Буфер обміну:** історія скопійованого з таймером автовидалення.
- **Перекладач**, **світовий час**, таймер, будильники, секундомір, нагадування звичайною мовою.
- **Ігри:** Steam, Epic, GOG і свої, друзі Steam онлайн, безкоштовні ігри Epic тижня.
- **Розробка:** понад 25 інструментів у теках: веб, дані, бази даних, Python, безпека, мережа.
- **Керування:** Wi-Fi, Bluetooth, гучність, яскравість, режим польоту, «Не турбувати».
- **Акаунти:** Telegram (вхід через QR), Spotify, Google (Gmail, Календар, YouTube), Steam, Discord, Epic Games.
- **Живі події:** запити Claude Code з кнопками ✓/✕, завершені завантаження, флешки, живлення, інтернет.
- 10 мов інтерфейсу, автоховання, теми й персонажі.

## Встановлення

1. Завантажте `Island-Setup-X.Y.Z.exe` з [релізів](../../releases/latest).
2. Запустіть. Програма поки не має цифрового підпису, тому Windows SmartScreen покаже попередження: «Докладніше» → «Все одно запустити».
3. Оновлення приходять самі: «Налаштування → Про програму».

## Приватність

Island працює на вашому ПК. Ключі, токени й сесії зберігаються зашифрованими (Windows DPAPI) і нікуди не надсилаються, крім самих сервісів, до яких ви підключаєтеся.
