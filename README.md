# Island для Windows

Island — панель у вигляді пілюлі вгорі екрана Windows 10 і 11. У згорнутому вигляді вона показує час, погоду або музику, що грає, і пропускає кліки до вікон під нею. Наведення курсора відкриває панель із вкладками.

**[Завантажити останню версію](../../releases/latest)** · [Сайт](https://freshman-69.github.io/Island-win/)

## Сповіщення й телефон

- Повідомлення Telegram з'являються на острові з полем відповіді.
- Сповіщення інших програм і події ПК: завантаження, флешки, заряд, Bluetooth, інтернет, перевантаження.
- Файли до 2 ГБ і текст передаються у ваше «Збережене» Telegram або через QR-код у домашній мережі, в обидва боки.
- Запити Claude Code на дозвіл показуються з кнопками «Дозволити» і «Відхилити».

## Встановлення

1. Завантажте `Island-Setup-X.Y.Z.exe` з [релізів](../../releases/latest).
2. Інсталятор не підписаний платним сертифікатом, тому Windows SmartScreen покаже попередження. Натисніть «Докладніше» → «Все одно запустити».
3. Після першого запуску острів коротко покаже свої вкладки. Нові версії Island пропонує встановити сам.

## Дані й безпека

- Нотатки, файли, історія буфера й налаштування зберігаються лише на вашому ПК.
- Токени й сесії шифруються засобами Windows (DPAPI) і передаються тільки тим сервісам, які ви підключили.
- Вхід у Steam і Google відкривається у вашому браузері; пароль Island не бачить.
- Перед встановленням оновлення перевіряються цифровий підпис і контрольна сума інсталятора.
- Анонімні лічильники запусків (без особистих даних) вимикаються в налаштуваннях.
